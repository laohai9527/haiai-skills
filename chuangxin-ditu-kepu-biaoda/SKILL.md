# 创新地图科普表达（老海AI补给站 · ABC 融合默认版）

**默认写法（2026-10-28 起）：A 骨架亲测 + B 钩子 + C 人味。**

| 代号 | 来源 | 借什么 | 不借什么 |
| --- | --- | --- | --- |
| A | 创新地图（王煜全）+ AI产品黄叔 | 翻案骨架、亲测日记、口语 | 创投黑话；黄叔编程/PM 赛道与江湖人设 |
| B | 刘小排（@bourneliu66） | 反常识标题、省流、「我不同意」短句硬判断 | builder/圈内赛道整套复刻 |
| C | 数字生命卡兹克 | 好奇式标题、窝火情绪现场、「愿你…」收束 | 长随笔、游戏/历史大比喻、Vibe Coding 主菜 |

落点仍是：**普通人今天怎么用 / 怎么开通**。

## 一句话公式

**亲测现场（可带窝火）+ 大众误解 + 硬翻案（「我不同意」/不是X是Y）+ 一句规律 + 三步行动 +（可选）愿你收束**

更短：**昨晚卡在哪 → 窝火一句 → 大家以为A → 我不同意，真正是B → 规律一句 → 今天点哪 → 愿你…**

## 何时用 / 何时不用

- **用**：科技/AI 热点解读、工具科普、开通与踩坑说明、贴图短评、图文快评。
- **少用/不用**：圈内黑话、All in AI 编程叙事、长篇转型/江湖致谢；重创投黑话、啤酒游戏等重类比、纯估值/泡沫叙事（可改成小白误解翻案）；长随笔、大比喻喧宾夺主。

## 写作步骤

1. **选题**：找 24–72 小时内可核验的新闻或用户高频痛点（封号、不会PS、开会员搞不清）。
2. **标题先钉钩子（B+C）**：反常识打断 + 可带「我忽然发现」式好奇；见下方模板。
3. **可选省流（B）**：贴图可省略；图文/长一点时，标题下 1–2 句写清「缺的不是A，是B + 今天补哪一步」。
4. **开场用黄叔人味（A）**：写一个「我刚卡在 / 我刚试完」的小现场（2–4 句）。
5. **可加窝火一句（C）**：情绪要具体、短，服务翻案，不写成抒情散文（如「玻璃门外看得见改不动」）。
6. **摸清大众第一反应**：恐慌 / 嘲笑 / 吹捧 / 「得先学会XX」。
7. **压一句翻案（A 钉 + B 口气）**：先单独成段写「我不同意。」（或等价硬判断），再写 `真正耽误你的不是A，是B`。翻案不可藏在形容词里。
8. **找 1 个决定性数字或硬事实**（没有数字就用可核对的官方口径）+ 亲测一句。
9. **规律一句**：机制人话；可补半句「工具再炫，若…还是…」。
10. **行动 ≤3 步**：打开哪、点哪、导出哪；可带模板包/服务入口。
11. **收束（C，可选但默认推荐）**：一句「愿你…」，回扣翻案，不鸡汤灌满。
12. **写后三问**：3秒知痛点？30秒感到反转？读完记得一条规律？

## 标题模板

1. `别再[旧办法]了——我忽然发现，卡死[痛点]的从来不是[A]`（ABC 融合首选）
2. `[热点/痛点]？真正耽误你的，不是A，是B`（A 经典）
3. `别再[旧办法]了——[痛点]卡死，往往不是[A]`（B 反常识）
4. `[不会XX也能…]之后，我忽然发现：卡死我的从来不是[A]`（C 好奇）
5. `[热点]！别慌/别急，真正[要保/值钱]的是[Y]`
6. 亲测感：`我不会XX，却用[工具]做出了[结果]`
7. 短刺判断：`[对象]，[废了/变了]` 或 `[主体]强在A，不在B`（慎用，需文内立刻解释）

## 正文骨架对照

| 步骤 | 写法 | 语气来源 |
| --- | --- | --- |
| 标题/省流 | 反常识 + 好奇；可选省流钉结论 | B + C |
| 现场 | 我卡在哪 / 刚亲测完 | A·黄叔 |
| 窝火 | 一句具体情绪/比喻，短 | C |
| 误解 | 大家第一反应写明 | A·王煜全 |
| 反转 | 「我不同意。」+ 不是X是Y（单独成段） | B + A |
| 规律 | 机制一句话（少黑话） | A |
| 行动 | 3步以内可执行；可带服务入口 | 共用 |
| 收束 | 「愿你…」回扣翻案 | C |

## 句式清单（必须至少各1）

- 第一人称亲测短句（「我试了一遍」「说句实话」）
- 口语短句、第二人称
- 「我不同意」或等价硬判断（B）
- 「不是A，是B」翻案句（硬钉，不可省略）
- 数字/官方口径后立刻给判断（一段最多1–2个决定性数字）
- 收尾「愿你…」回扣翻案（C，贴图极短版可省）
- 服务入口保留 `https://haiai.vip`

## Checklist

### 写前
- [ ] 有可核验事实或用户真实痛点
- [ ] 标题有反常识或「忽然发现」式好奇
- [ ] 有一句「我刚……」现场（或等价亲测感）
- [ ] 大众第一反应已写明
- [ ] 翻案句已压成一句且单独成段（建议先「我不同意」）
- [ ] 行动能落到「打开哪、点哪、导出哪」

### 写中
- [ ] 100字内出现冲突/反转
- [ ] 没有只学日记/窝火、漏掉翻案
- [ ] 没有只学骨架、读起来像说明书
- [ ] 窝火比喻不超过一句，不写成随笔
- [ ] 贴图用短词小节或分点，方便做卡
- [ ] 少形容词，多阶段/机制词：门槛、流程、替换成本、备份、路径

### 写后
- [ ] 删鸡汤；每句给事实、机制或动作（「愿你」只留一句）
- [ ] 读出声像口播（糙一点可以，端着不行）
- [ ] 结尾回扣标题里的「真正……」或「从来不是」
- [ ] 没有站成情绪喷子，站成阶段判断者
- [ ] 没有写进编程/Agent 圈内黑话（除非选题本身是给小白解释黑话）

## 科普适配铁律

相对原创新地图：
- 「往哪布局」→「今天怎么用」
- 产业生态类比 → 使用路径/门槛差
- 保留翻案与数字钉死，去掉创投腔

相对原黄叔：
- 学人味与亲测感，不学赛道与人设深度
- 读者默认是「普通人把 AI 用上」，不是产品经理/想用 AI 编程的人

相对刘小排 / 卡兹克：
- 只借钩子、省流、硬判断、窝火短句与愿你收束
- 不整套复刻其人设、赛道或长文气质

## 示范锚点（Canva Craft · ABC 融合）

- 标题：`别再学PS了——我忽然发现，卡死封面的从来不是画`
- 省流：缺的不是更会画的模型，是出完还能改的那一步
- 翻案钉：`我不同意。` + `真正耽误你的，不是不会画——是出完改不动`
- 窝火：玻璃门外看得见、改不动
- 规律：`封面这件事，出图和解题是两步；你缺的常常是第二步`
- 收束：`愿你会用上 AI，也愿你改得动自己做出来的东西`
- 完整示范：`examples/10-Canva-Craft-ABC融合.txt`

## 输出格式

交给用户时默认给：
1. 标题建议（1–2个）
2. 正文全文（含可选省流）
3. 一句「改动要点」（翻案点 + 钩子/窝火/愿你各用了啥）

若用户只要贴图短版：压到 400 字内，保留翻案钉、三步行动与服务入口；省流与「愿你」可二选一保留。
