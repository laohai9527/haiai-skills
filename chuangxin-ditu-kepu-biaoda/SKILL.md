# 创新地图科普表达（老海AI补给站 · 搭配版）

**王煜全给翻案骨架，黄叔给人味与亲测感；落点仍是「今天怎么用 / 怎么开通」。**

对标来源：
- 骨架：微信公众号「创新地图」（王煜全）— 新闻钩子 + 认知翻案 + 规律 + 行动
- 语气：微信公众号「AI产品黄叔」— 第一人称实战日记、口语、别端着（只学语气，不学其编程/PM 赛道与江湖人设）

## 一句话公式

**亲测现场 + 大众误解 + 硬翻案（不是X是Y）+ 一句规律 + 三步行动**

更短：**昨晚卡在哪 → 大家以为A → 真正是B → 规律一句 → 今天点哪**

## 何时用 / 何时不用

- **用**：科技/AI 热点解读、工具科普、开通与踩坑说明、贴图短评、图文快评。
- **少用/不用**：黄叔式圈内黑话、All in AI 编程叙事、长篇转型/江湖致谢；王煜全式重创投黑话、啤酒游戏等重类比、纯估值/泡沫叙事（可改成小白误解翻案）。

## 写作步骤

1. **选题**：找 24–72 小时内可核验的新闻或用户高频痛点（封号、不会PS、开会员搞不清）。
2. **开场用黄叔人味**：写一个「我刚卡在 / 我刚试完」的小现场（2–4 句），别一上来念说明书。
3. **摸清大众第一反应**：恐慌 / 嘲笑 / 吹捧 / 「得先学会XX」——这是要翻的案。
4. **压一句翻案（王煜全钉）**：`真正重要的不是X，是Y`（或「真正耽误你的不是A，是B」）。必须单独成段，不能藏在形容词里。
5. **找 1 个决定性数字或硬事实**（没有数字就用可核对的官方口径）。
6. **选 1 个轻量类比**（出图+改图拆成两件事、燃料+机器）；类比只服务一个结论。
7. **按五段写**（贴图 300–600 字；图文可加长但仍守节奏）：
   - 现场：我卡在哪 / 刚试了啥
   - 误解：大家第一反应
   - 反转：不是X是Y
   - 规律：为什么会这样（人话一句）
   - 行动：读者今天可做的具体一步（≤3步）
8. **标题**：优先套下面模板之一。
9. **写后三问**：3秒知痛点？30秒感到反转？读完记得一条规律？

## 标题模板

1. `[热点/痛点]？真正耽误你的，不是A，是B`
2. `[热点]！别慌/别急，真正[要保/值钱]的是[Y]`
3. `[对象]火了？大家都在卷A，赢家其实靠B`
4. `一家/一个做X的[工具]，关键居然不是X`
5. 亲测感：`我不会XX，却用[工具]做出了[结果]`（黄叔味标题，正文仍要钉翻案）
6. 短刺判断：`[对象]，[废了/变了]` 或 `[主体]强在A，不在B`（慎用，需文内立刻解释）

## 开篇壳（可替换）

亲测日记优先（黄叔味）：

```
你好，我是老海。
AI模型开通 → https://haiai.vip

[昨晚/今天下午]又卡在[痛点]了。
[2–3句现场：图有了字不对 / 账号又……]
```

快评壳（更贴王煜全口播）：

```
你好，我是老海，这里是老海AI补给站今日快评。
今天只记一句：[翻案金句]。
```

然后：大众第一反应 → 「但真正……」

## 正文骨架对照

| 步骤 | 写法 | 语气来源 |
| --- | --- | --- |
| 现场 | 我卡在哪 / 刚亲测完 | 黄叔 |
| 误解 | 大家第一反应写明 | 王煜全（为翻案铺垫） |
| 反转 | 真正重要的不是X，是Y（单独成段） | 王煜全 |
| 规律 | 机制一句话（少黑话） | 王煜全 |
| 行动 | 3步以内可执行；可带服务入口 | 二者共用 |

## 句式清单（必须至少各1）

- 第一人称亲测短句（「我试了一遍」「说句实话」）
- 口语短句、第二人称
- 「不是A，是B」翻案句（硬钉，不可省略）
- 数字/官方口径后立刻给判断（一段最多1–2个决定性数字）
- 收尾可回扣翻案句；服务入口保留 `https://haiai.vip`

## Checklist

### 写前
- [ ] 有可核验事实或用户真实痛点
- [ ] 有一句「我刚……」现场（或等价亲测感）
- [ ] 大众第一反应已写明
- [ ] 翻案句已压成一句且单独成段
- [ ] 行动能落到「打开哪、点哪、导出哪」

### 写中
- [ ] 100字内出现冲突/反转
- [ ] 没有只学黄叔日记、漏掉翻案
- [ ] 没有只学王煜全骨架、读起来像说明书
- [ ] 贴图用短词小节或分点，方便做卡
- [ ] 少形容词，多阶段/机制词：门槛、流程、替换成本、备份、路径

### 写后
- [ ] 删鸡汤；每句给事实、机制或动作
- [ ] 读出声像口播（糙一点可以，端着不行）
- [ ] 结尾回扣标题里的「真正……」
- [ ] 没有站成情绪喷子，站成阶段判断者
- [ ] 没有写进编程/Agent 圈内黑话（除非选题本身是给小白解释黑话）

## 科普适配铁律

相对原创新地图：
- 「往哪布局」→「今天怎么用」
- 产业生态类比 → 使用路径/门槛差
- 保留翻案与数字钉死，去掉创投腔

相对原黄叔：
- 学人味与亲测感，不学赛道与人设深度
- 读者默认是「普通人把 AI 用上」，不是产品经理/想用 AI 编程的人

## 示范锚点（Canva Craft 贴图）

- 翻案钉：`真正耽误你的，不是不会画，是出完改不动`
- 规律：`封面这件事，出图和解题是两步；你缺的常常是第二步`
- 现场：昨晚卡在封面（图有了字不对）
- 完整示范见仓库旁笔记或对话成稿「王煜全骨架+黄叔人味」版

## 输出格式

交给用户时默认给：
1. 标题建议（1–2个）
2. 正文全文
3. 一句「改动要点」（翻案点是什么 + 人味开场用了啥）

若用户只要贴图短版：压到 400 字内，保留翻案钉、三步行动与服务入口。
