# 创新地图科普表达（老海AI补给站适配版）

把王煜全「创新地图 / 要闻评论」的表达骨架，改成面向普通人的 AI 科普写法。

## 一句话公式

**新闻钩子 + 认知翻案 + 产业/使用规律（人话）+ 行动视角**

更短：**热点 → 不是X是Y → 一句规律 → 今天能做的一步**

## 何时用 / 何时不用

- **用**：科技/AI 热点解读、工具科普、开通与踩坑说明、贴图短评、图文快评。
- **不用原样搬**：重创投黑话、啤酒游戏等重类比、纯估值/泡沫叙事（可改成小白误解翻案）。

## 写作步骤

1. **选题**：找 24–72 小时内可核验的新闻或用户高频痛点（封号、不会PS、开会员搞不清）。
2. **摸清大众第一反应**：恐慌 / 嘲笑 / 吹捧 / 二分法——这是要翻的案。
3. **压一句翻案**：`真正重要的不是X，是Y`（或「真正耽误你的不是A，是B」）。
4. **找 1 个决定性数字或硬事实**（没有数字就用可核对的官方口径）。
5. **选 1 个轻量类比**（燃料+机器、出图+改图拆成两件事）；类比只服务一个结论。
6. **按四段写**（贴图 300–600 字；图文可加长但仍守节奏）：
   - 信息：主体 + 事实
   - 反转：不是X是Y
   - 规律：为什么会这样（人话）
   - 行动：读者今天可做的具体一步
7. **标题**：优先套下面模板之一。
8. **写后三问**：3秒知热点？30秒感到反转？读完记得一条规律？

## 标题模板

1. `[热点]！别慌/别急，真正[要保/值钱]的是[Y]`
2. `[误解]？真正耽误你的，不是A，是B`
3. `[对象]火了？大家都在卷A，赢家其实靠B`
4. `一家/一个做X的[工具]，关键居然不是X`
5. 短刺判断：`[对象]，[废了/变了]` 或 `[主体]强在A，不在B`（慎用，需文内立刻解释）

## 开篇壳（可替换）

```
你好，我是老海，这里是老海AI补给站今日快评。
今天只记一句：[翻案金句]。
```

然后：热点场面 → 大众第一反应 → 「但真正……」

## 正文骨架对照

| 步骤 | 写法 |
| --- | --- |
| 信息 | 刚发生的事 / 高频私信痛点 + 1个硬事实 |
| 反转 | 真正重要的不是X，是Y |
| 规律 | 机制一句话（少黑话） |
| 行动 | 3步以内可执行；可带服务入口 |

## 句式清单（必须至少各1）

- 口语短句、第二人称
- 反问一句
- 「不是A，是B」翻案句
- 数字后立刻给判断（一段最多1–2个决定性数字）
- 收尾签：`老海AI补给站，我们明天见。`（可按账号改）

## Checklist

### 写前
- [ ] 有可核验事实或用户真实痛点
- [ ] 大众第一反应已写明
- [ ] 翻案句已压成一句
- [ ] 行动能落到「打开哪、点哪、导出哪」

### 写中
- [ ] 100字内出现冲突/反转
- [ ] 贴图用短词小节或分点，方便做卡
- [ ] 少形容词，多阶段/机制词：门槛、流程、替换成本、备份、路径

### 写后
- [ ] 删鸡汤；每句给事实、机制或动作
- [ ] 读出声像口播
- [ ] 结尾回扣标题里的「真正……」
- [ ] 没有站成情绪喷子，站成阶段判断者

## 科普适配铁律（相对原创新地图）

- 把「往哪布局」改成「今天怎么用」
- 把产业生态类比改成使用路径/门槛差
- 保留翻案与数字钉死，去掉创投腔与过重管理学典故

## 输出格式

交给用户时默认给：
1. 标题建议（1–2个）
2. 正文全文
3. 一句「改动要点」（翻案点是什么）

若用户只要贴图短版：压到 400 字内，保留三步行动与服务入口。
